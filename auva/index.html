基本タグ

          
[[tag:"テキスト"]]     → <tag>テキスト</tag>
[tag:"テキスト"]       → 同上（単括弧）
[img](src="a.png")     → 空要素 / void タグ
[ul: [li:"a"] [li:"b"]] → ネスト可


          
ブロック（div）

          
((
  [[h2:"見出し"]]
  [[p:"本文"]]
))(class="card")


          
変数

          
<value>
  name = "値"
  n = 10
  flag = true
  list = ["a", "b", 3]
  obj = {key: "val"}
</value>

{name}          → 補間
{list[1]}       → 1始まりインデックス
{len[list]}     → 長さ
